Safety boundary

  • All compression work runs in a disposable Web Worker.
  • Input is capped at 16 KB and each run has an eight-second circuit breaker.
  • Cancel immediately terminates the worker.
  • Heap figures are shown only when the browser exposes an applicable API; buffer estimates are labelled separately.
