Usage example

const response = await fetch('/data/tracker/stellar-neighborhood.json');
const snapshot = await response.json();
console.log(snapshot.statistics, snapshot.sources);

Respect source attribution embedded in each snapshot. JSONL clients should parse one JSON object per line. Data may change between site releases, so bind to documented fields and handle missing values.
