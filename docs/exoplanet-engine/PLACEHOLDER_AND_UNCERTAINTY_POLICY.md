# Appearance and uncertainty policy

Policy `appearance-capabilities-1` evaluates usable constraints and model domains.
Distance, graphics hardware and catalogue confirmation do not select appearance
quality. No catalogue-field count or global percentage is treated as accuracy.

| State | Implemented presentation |
|---|---|
| Identity/candidacy with no applicable appearance input | Source-linked, labelled wireframe schematic; no physical radius or physical surface navigation. |
| Radius estimate | Its adopted physical radius is retained; material and environment remain conditional. |
| Radius limit/interval | Its constraint is retained as partial support; no nominal physical radius is invented. |
| Useful evidence outside an available model | Evidence stays visible and the model limitation is disclosed. |
| Candidate, disputed or retracted interpretation | The reviewed status persists in the viewer, report, screenshot and shared state. |
| False positive | Preserve the KOI disposition without describing it as a retracted publication or a confirmed planet. |
| Explicit sandbox | Persistent speculative label; assumed values remain outside scientific records. |
| GPU/network/integrity failure | A separate operational state; compatible cached data or a schematic remains usable. |

The default source-only view is deliberately schematic. A conditional scenario
can then use supported size and host inputs while exposing pressure, temperature,
material, atmospheric composition, reference gravity, phase and spatial priors.
No unsupported terrain, clouds, oceans, moons or rings are silently introduced.

`observation_constrained` is reserved for a validated feature model meeting its
evidence requirements. The current broad catalogue and simple optical models do
not receive that label merely from spectrum counts or a confirmed existence flag.
The two visible albedo bands affect a conditional colour model and retain their
unmeasured-wavelength assumptions.

The real sparse fixture is K00129.02: the accepted source reports a candidate and
an orbital period, but no usable appearance inputs in the reviewed subset. The
two-million-light-year existence-only example is exclusively a synthetic test.
It has no invented NASA paper or production catalogue entry.

Built-in captures and JSON reports retain status, mode, evidence release, recipe,
assumptions and source references. Unknown physical units never inherit the
arbitrary scale used by the schematic drawing.
